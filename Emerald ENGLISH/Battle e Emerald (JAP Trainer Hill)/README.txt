Those cards are only compatible with the Japanese Emerald restoration project available here : https://github.com/Youpileouf/pokeemerald

To use them, you'll have to unlock Mystery Gift.

These can be achieved at the ODALE TOWN Pokemart by completing the questionnaire : LINK TOGETHER WITH ALL

When Mystery Gift is unlock, launch Mystery Gift then connect a second GBA with an e-Reader using a Link cable.
